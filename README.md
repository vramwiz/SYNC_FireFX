# 火演出（SYNC_FireFX）

AviUtl2の「SYNC」に登録するメディアオブジェクトです。外部の画像や動画を使わず、炎、燃焼煙、火の粉、赤熱を描画します。バージョンは v1.0.0、対象環境は Windows 64bit / AviUtl2 v2.1.16以降です。

## 使い方

1. `SYNC_FireFX.zip` を展開し、`SYNC_FireFX` フォルダを `C:\ProgramData\aviutl2\Plugin\` に置きます。
2. レイヤー編集で「メディアオブジェクトを追加」から「火演出」を追加します。配置直後はろうそくの炎が表示されます。
3. 「プリセット選択」で種類を選び、「設定」を押します。反映後は各項目を個別に調整できます。X、Y、Z、拡大率、透明度は AviUtl2 の基底オブジェクト側で調整します。

プリセットは、ろうそく、ガスコンロ、焚き火、たいまつ、暖炉、アルコールランプ、ガスバーナー、炭火、火災、線香、線香花火、火柱の12種類です。

## 点火と消火

「燃焼」の「火力」をタイムラインで動かします。火力0で消火、1で最初の火元に着火し、2で設定したすべての火元が点火します。100が標準で、150まで設定できます。ガスコンロは標準設定で点火位置から円周の両方向へ燃え広がります。消火時の煙と赤熱は、保存済みの火力変化を読み取って計算します。

「物体干渉」の相対座標は火元の配置中心が基準で、物体を上に置くときは相対Yを負にします。鍋や鉄板の画像は別オブジェクトで重ねてください。

「陽炎」は背景バッファを受け取れるときに使用できます。背景を先に描画するレイヤー順にして、「陽炎を有効にする」をオンにします。
